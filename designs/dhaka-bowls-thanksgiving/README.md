# Dhaka Bowls — Thanksgiving Flier

Standalone, one-page Letter flier, built from the Claude Design project "Dhaka Bowls Thanksgiving flier".
Open `index.html` in a browser. Print or save as PDF for a full-bleed 8.5×11 sheet.

Hero photo: `index.html?photo=vegetable-dal` (default), `egg-curry`, or `saag-dal`.
