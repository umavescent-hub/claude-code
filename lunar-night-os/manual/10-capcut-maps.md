# Where everything is in CapCut

Open the Find tab and type what you want. It shows the path, the house value and a tappable replica of the screen. This chapter is the same map on paper.

## CapCut Mobile

**LAW: select the clip first; the toolbar changes with what is selected.**

| Job | Path |
|---|---|
| Split | Select clip › `Split` |
| Speed curve | `Speed › Curve › Custom` |
| Keyframe | Diamond icon above the timeline |
| Overlay | `Overlay › Add overlay` |
| Blend | Select overlay › `Blend` |
| Mask | Select clip › `Mask` |
| Adjust / HSL | `Adjust › HSL` |
| Effects | `Effects › Video effects` |
| Text | `Text › Add text` |
| Captions | `Captions › Auto captions` |
| Beats | Select music › `Beats` |
| Export | Resolution button top-right › `Export` |

> [!VERIFY] Toolbar order
> Toolbar order and some Pro badges change between builds. If a tool is missing, scroll the bottom toolbar or use Find › "match my app".

## CapCut Desktop

**LAW: Desktop is where LUTs, fonts and long timelines live.**

| Job | Path |
|---|---|
| LUT | `Adjustment › LUT › Import` |
| Keyframe | Diamond in the right panel |
| Text and fonts | `Text` panel › font list |
| Export | `Export` top-right |

## Export settings

Night Reel and Marketplace: 1080p or 4K, 30 fps (60 when slow-motion was shot), highest bitrate, 9:16. Documentary: 4K 24, 16:9 or 9:16.

## Blackmagic Camera and Pixel Camera

Find also maps both camera apps: Blackmagic's HUD (ISO, shutter, WB, LUT, zebras) and Pixel Camera's video settings (resolution, frame rate, 10-bit HDR, stabilization). Use them with the Rig presets.

> [!RECALL] Where is the speed curve? :: Speed › Curve › Custom
> [!RECALL] Where do you import a LUT on Desktop? :: Adjustment › LUT › Import
> [!RECALL] Why does the toolbar change? :: It follows what is selected
> [!RECALL] What do you do when a tool is missing? :: Scroll the toolbar or use Find › match my app
> [!RECALL] Export frame rate when you shot slow-mo? :: 60 fps
> [!RECALL] Which tab finds any control by name? :: Find
